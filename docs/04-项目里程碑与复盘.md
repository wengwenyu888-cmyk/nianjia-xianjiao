# 04 项目里程碑与复盘

## 团队模型（2026-10-12 定）
- 开发：CTO 一人 + AI 全量辅助；实习生**不写代码**，全程观察 + 阅读 docs/ 沉淀资料（面试用途）。
- 沉淀机制：CTO 每周把开发过程（决策、踩坑、复盘）更新进本文件与 03 面试知识库，实习生据此学习。

## 12 周计划（起始 2026-10）
| 周 | 里程碑 | 交付物 |
|---|---|---|
| W1–2 | 领域学习+设计 | 读完 01 手册、需求走查、数据模型设计定稿 |
| W3–4 | 工程骨架 ✅ 2026-10-12 完成 | 三端脚手架（79 文件）、26 表 ORM+迁移、主数据模块（后端 9 端点+前端 4 页面，38 测试全过） |
| W5–6 | 要货闭环 | 要货单创建 → 店长确认 → 总部汇总 |
| W7–8 | 配送闭环 | 分拣单、配送单、司机工作台（网页）、电子签收 |
| W9–10 | 结算与核算 | 对账单、门店盈亏核算、KPI 报表 |
| W11 | 智能体 v1 | 要货助手（规则版）+ 配货计划助手 |
| W12 | 试点上线 | 5–10 家店双轨并行、修复、切换 |

> 日期与内容随实际进度更新。

## 周复盘模板（每人每周五填，兼作面试素材）
- 本周做了什么（具体模块/功能，最好带数字）
- 遇到什么卡点、怎么解决的
- 学到什么（对应 03 面试库哪几行）
- 下周计划
