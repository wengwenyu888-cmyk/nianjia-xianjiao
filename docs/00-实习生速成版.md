# 00 实习生速成版（面试前 30 分钟）

> 本文件是 docs/ 全套文档的浓缩。面试前过一遍，细节回 01/02/03 查。

## 1. 一句话项目
念家鲜饺（山东潍坊，约 50 家纯直营鲜饺连锁）：我参与开发**供应链系统**——门店要货 → 总部汇总 → 分拣 → 配送 → 签收 → 对账闭环，含 2 个 LLM 智能体（要货助手、配货计划助手）。总部统采统配，馅料保质期以小时计，全链路批次可追溯。

## 2. 技术栈一句话
FastAPI(Python) + Vue3 + MySQL + Electron 桌面壳(Windows) + 腾讯云容器部署 + DeepSeek API 做智能体建议。客户端 = 响应式网页 + 桌面壳包装。

## 3. 必须会说的 15 个词
SKU（最小库存单元）、批次（追溯最小单位）、FIFO（先进先出）、安全库存、损耗率、要货单/分拣单/配送单、POD（签收凭证）、对账、内部盈亏核算（每店独立算利润）、KPI、账期、冷链、统采统配、SaaS（租用制软件）、动态扩容（加副本不搬数据）。

## 4. 架构一句话
响应式网页（总部/门店/司机三合一工作台）+ Electron 桌面壳 → FastAPI 业务服务（主数据/要货/库存/配送/结算）→ 数据库；智能体独立服务只出建议；对接银豹（进销量流水）、金蝶（出财务凭证）、管家婆（过渡期对账）。

## 5. 最可能被问的 10 问（答案索引）
1. 介绍项目 → 背熟第 1 节。
2. 库存并发扣减怎么防超卖 → 事务+行锁 / 乐观锁（03「库存并发扣减」）。
3. 为什么 LLM 不算账 → 确定性内核 + LLM 薄层：算错账比说错话严重（03「LLM 薄层架构」）。
4. 多单位怎么建模 → 基础单位 + 换算系数表（03「多单位换算」）。
5. 动态扩容怎么做 → 无状态容器多副本 + 云 RDS 升配（01 §6.3）。
6. 新老系统怎么切换 → 双轨并行 2–4 周对账后切（02「已定设计决策」）。
7. REST API 设计要点 → 资源命名、幂等、分页、鉴权（03「API 设计」）。
8. 数据库事务/索引 → 03 对应行。
9. 数据可追溯怎么保证 → 批次号贯穿单据链（03「批次与追溯」）。
10. 你的贡献是什么 → 04 里程碑里挑自己写的模块讲，附数字（单据量/店数）。
