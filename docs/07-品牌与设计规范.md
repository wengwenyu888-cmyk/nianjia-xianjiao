## 3. 视觉原则（V3：Apple 官网设计语言 × 品牌调性）
用户明确要求参考 Apple 官网设计。结合吉祥物调性（现代/年轻/可爱/温暖/亲民）落地为：
- **大量留白**：奶油白底 #FBF6EA，区块间留白是第一组织手段，少用边框/分割线
- **大字号层级**：页面标题 32-48px 粗黑体、区块标题 20-24px、正文 14-15px；
  标题用系统字体栈最粗档（如 "PingFang SC", "Microsoft YaHei" 的 700/800 字重）
- **克制的色彩**：整页只有绿（行动）+ 黑（文字）+ 白（底），金黄/橙红仅做点缀；
  不用大面积彩色块，banner 用深绿渐变 + 白字
- **精致细节**：大圆角（卡片 16px、按钮 8px）、柔和阴影（0 8px 24px rgba(0,0,0,.06)）、
  顶部导航毛玻璃半透明（backdrop-filter）、hover 微过渡 0.2s
- **吉祥物**：frontend-web/src/assets/mascot-green.png（深绿底版）用于登录页与首页主视觉；
  构图遵循「图右文左」或「图上文下」的 Apple 式大图版面
- Element Plus 主题定制走 CSS 变量覆盖，不引入新 UI 库
