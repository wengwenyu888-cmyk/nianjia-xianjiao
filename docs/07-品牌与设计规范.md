## 2. 色板（实测主色 + 设计延伸）
| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 primary | #157fd1 | 按钮、链接、强调 |
| 深蓝 ink | #0e346b | 侧边栏、标题、页脚 |
| 天蓝 gradient | #0f92d2 | 渐变搭档、hover |
| 蓝灰 slate | #707c9d | 辅助文字、次级信息 |
| 浅蓝雾 | #7f97bc | 边框、分割线 |
| 暖米底 | #faf6f0 | 页面背景（「家的温度」用暖白表达） |
| 金黄点缀 | #f5a623 | 饺子元素点缀（logo 图形/角标，谨慎使用） |

## 3. 视觉原则
- 蓝 = 信赖与品质（实测品牌主色）；暖米白底 + 白卡片 = 家的温度；金黄仅作饺子图形点缀
- 圆角 8px 起，卡片圆角 12px；阴影柔和
- 字体：系统字体栈（不引外部字体，服务器带宽优先）；标题加粗 + 字距
- Element Plus 主题定制走 CSS 变量覆盖（--el-color-primary 系列），不引入新 UI 库
