念家鲜饺供应链系统

面向鲜饺连锁直营门店的供应链管理平台：门店要货 → 总部汇总 → 分拣 → 配送 → 签收 → 对账，全链路闭环，含采购入库、批次库存与临期预警、 AI 要货建议（规则引擎）。已部署在生产服务器持续运行。

FastAPI Vue3 + Element Plus MySQL 8 Electron 桌面端 Docker 部署 AI 智能体
  • 门店要货 → 汇总 → FIFO 分拣 → 配送 → 电子签收 → 对账全闭环
  • 批次库存 + 批次流水双轨记账，结存与流水恒等式一致
  • 采购收货入库、临期与低库存自动预警
  • AI 要货建议（近 7 天销量 × 星期系数，结合库存与效期）
  • 权限点 RBAC + 门店数据隔离；Windows 桌面客户端
